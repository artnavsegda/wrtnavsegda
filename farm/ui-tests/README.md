# UI-тесты (Playwright)

Проверяют живой интерфейс фермы: платформы, flavor, пакеты, выбор, конфиги,
страницу платформы. Действия сборки/публикации подменяются через `page.route`,
поэтому тесты ничего не собирают и не публикуют.

```sh
npm install
npx playwright test
```

По умолчанию идут на `http://192.168.245.248:8099` (нужен доступ в локальную
сеть). На macOS Chrome, запущенный Playwright, в локальную сеть часто не пускают,
поэтому удобнее туннель:

```sh
ssh -f -N -L 18099:127.0.0.1:8099 art@192.168.245.248
FARM_URL=http://127.0.0.1:18099 npx playwright test
```

Переменные: `FARM_URL`, `FARM_BROWSER` (по умолчанию `chrome`).
